Dual-Branch Ensemble

Two complementary vision backbones, each specialized for different manipulation signals, merged via learnable Platt scaling.

ConvNeXt-V2-Base

Temperature-Scaled Ensemble

Fake Face — Grad-CAM

Generalisation Analysis

The cross-dataset drop is expected — Celeb-DF v2 uses different compression, actors, and lighting. The v4 anti-overfit techniques (dropout, label smoothing, augmentation) ensure the model learns genuine manipulation signals rather than dataset-specific shortcuts.
